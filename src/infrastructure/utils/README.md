# Утилиты инфраструктуры

## Logger

Утилита для дебаг логирования с поддержкой переменных окружения.

### Использование

1. Создайте файл `.env` в корне проекта (если его еще нет)
2. Добавьте переменную `VITE_DEBUG=true` для включения дебаг логов
3. Импортируйте функции из `@/infrastructure/utils/logger`

### Пример

```typescript
import {
  debugLog,
  debugWarn,
  debugError,
  debugGroup,
  debugGroupEnd,
} from '@/infrastructure/utils/logger';

// Простой лог
debugLog('Компонент инициализирован', { id: 123 });

// Предупреждение
debugWarn('Предупреждение');

// Ошибка
debugError('Произошла ошибка', error);

// Группировка логов
debugGroup('Инициализация');
debugLog('Шаг 1');
debugLog('Шаг 2');
debugGroupEnd();
```

### Переменные окружения

- `VITE_DEBUG` - установите в `'true'` для включения дебаг логов, в `'false'` или не устанавливайте для выключения

### Примечание

Все функции проверяют переменную окружения `VITE_DEBUG` перед выводом в консоль. Если она не установлена или равна `'false'`, логи не будут выводиться.
