# Система регионов и карта

## Разделение карты на зоны

Карта будет разделена на **регионы** (зоны) для улучшения производительности и геймплея:

- **Размер региона**: 100×100 клеток
- **Независимость**: каждый регион может развиваться независимо
- **Связность**: регионы соединяются дорогами, транспортными артериями
- **Владение**: регионы закреплены за конкретным игроком (задел на мультиплеер)
- **Покупка**: регионы нужно покупать для получения контроля над ними

### Преимущества региональной системы

1. **Производительность**: симуляция может обрабатывать активные регионы, остальные — агрегированно
2. **Масштабируемость**: возможность создавать огромные города из множества регионов
3. **Мультиплеер**: каждый игрок управляет своими регионами
4. **Специализация**: регионы могут специализироваться (промышленный, жилой, деловой)
5. **Политики**: разные законы и правила в разных регионах

## Покупка регионов

Регионы не даются автоматически — их нужно **покупать** для получения контроля:

- **Начало игры**: игрок получает стартовый регион (или несколько)
- **Расширение**: покупка соседних регионов для расширения города
- **Стоимость**: зависит от характеристик региона (см. ниже)
- **Ограничения**: можно покупать только соседние регионы (или через специальные механики)

## Полезные ресурсы на карте

На карте должны быть **области с полезными ресурсами**:

### Типы ресурсов

1. **Полезные ископаемые**
   - Уголь, нефть, газ (энергетика)
   - Железная руда, медь, алюминий (металлургия)
   - Известняк, песок, глина (строительство)
   - Редкие металлы (электроника)

2. **Природные ресурсы**
   - Лес (деревообработка)
   - Водные ресурсы (чистая вода, рыба)
   - Плодородная почва (сельское хозяйство)
   - Геотермальные источники (энергетика)

3. **Специальные ресурсы**
   - Туристические достопримечательности
   - Исторические объекты
   - Природные заповедники
   - Минеральные источники

### Механика ресурсов

- **Добыча**: строительство шахт, скважин, карьеров
- **Обработка**: переработка сырья в товары
- **Торговля**: продажа ресурсов другим регионам
- **Исчерпаемость**: некоторые ресурсы могут закончиться
- **Экология**: добыча влияет на окружающую среду

## Стоимость региона

Стоимость региона зависит от нескольких факторов:

### 1. Место доступное для застройки

- **Площадь пригодной земли**: сколько клеток можно застроить
- **Рельеф**: равнины дешевле, горы дороже
- **Водоемы**: наличие рек, озер (плюс и минус)
- **Существующая инфраструктура**: дороги, коммуникации

**Формула влияния:**
- Больше пригодной земли → выше стоимость
- Сложный рельеф → дополнительная стоимость
- Готовая инфраструктура → премиум к стоимости

### 2. Полезные ископаемые

- **Тип ресурсов**: редкие ресурсы увеличивают стоимость
- **Запасы**: объем доступных ресурсов
- **Доступность**: легкость добычи (глубина, рельеф)
- **Спрос**: текущая рыночная ценность ресурсов

**Формула влияния:**
- Наличие ресурсов → значительное увеличение стоимости
- Редкие/ценные ресурсы → премиум к стоимости
- Легкодоступные ресурсы → дополнительная стоимость

### 3. Базовая экология

- **Уровень загрязнения**: чистая экология дороже
- **Биоразнообразие**: наличие лесов, водоемов
- **Климат**: благоприятные условия
- **Риски**: наводнения, оползни, сейсмика

**Формула влияния:**
- Чистая экология → премиум к стоимости
- Загрязненные регионы → скидка
- Природные риски → снижение стоимости

### Итоговая стоимость

```
Базовая стоимость = площадь × коэффициент_рельефа
+ стоимость_ресурсов × запасы × ценность
+ экологический_бонус × чистота
- экологические_риски × вероятность
```

### Примеры стоимости

- **Пустой равнинный регион**: базовая стоимость
- **Регион с углем**: +50-100% к стоимости
- **Регион с редкими металлами**: +200-300% к стоимости
- **Экологически чистый регион**: +30-50% к стоимости
- **Загрязненный промышленный регион**: -20-40% к стоимости

## Изометрическая сетка

Основа визуализации и логики:

- **Клеточная структура**: карта состоит из клеток (тайлов)
- **Изометрическая проекция**: классический градостроительный вид
- **Гибкий размер**: объекты могут занимать разное количество клеток

### Размеры объектов

**Дороги:**
- Могут быть шириной 1, 2, 3+ клетки
- Узкие улицы: 1 клетка (односторонние, дворовые)
- Обычные дороги: 2 клетки (двусторонние)
- Проспекты: 3+ клетки (многополосные магистрали)

**Здания:**
- Могут занимать четное и нечетное количество клеток
- Маленькие: 1×1, 2×2 (киоски, небольшие дома)
- Средние: 3×3, 4×4 (жилые дома, магазины)
- Большие: 5×5, 6×6+ (заводы, торговые центры, стадионы)
- Нестандартные формы: L-образные, Т-образные здания
