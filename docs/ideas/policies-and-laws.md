## Концепция системы

### Иерархия

```
Политика (Policy)
  ├─ Закон 1 (Law)
  ├─ Закон 2 (Law)
  ├─ Закон 3 (Law)
  └─ Закон N (Law)
```

### Определения

- **Закон (Law)** — атомарное правило, влияющее на один аспект игры
- **Политика (Policy)** — набор законов, объединенных общей целью
- **Временная политика (Temporary Policy)** — краткосрочная политика для событий
- **Регион** — территория, к которой применяются политики

## Типы политик

### 1. Постоянные политики (Permanent Policies)

**Характеристики:**
- Действуют бессрочно до отмены
- Стандартная стоимость законов
- Постепенное накопление эффектов
- Влияют на долгосрочное развитие

**Примеры:**
- "Зеленый город"
- "Деловой центр"
- "Социальный район"

### 2. Временные политики (Temporary Policies)

**Характеристики:**
- Действуют ограниченное время (от 3 до 30 дней)
- Стоимость законов **в 2-3 раза выше**
- Эффективность законов **в 2-3 раза выше**
- Быстрый, но дорогой эффект

**Применение:**
- Акции и мероприятия
- Праздники (Новый год, национальные праздники)
- Кризисные ситуации (выборы, происшествия)
- Сезонные события

**Механика создания:**
1. Игрок выбирает 3-5 законов из каталога
2. Устанавливает длительность (3-30 дней)
3. Система рассчитывает стоимость с учетом множителей
4. Политика применяется к выбранным регионам

**Примеры:**
- "Новогодняя ярмарка" (14 дней)
- "Неделя экологии" (7 дней)
- "Предвыборная кампания" (30 дней)
- "Антикризисная программа" (до 30 дней)

## Стоимость законов

### Базовая стоимость

Каждый закон имеет **стоимость в день** (daily cost):

```typescript
interface Law {
  id: string;
  name: string;
  dailyCost: number; // в игровой валюте
  effects: Effect[];
  // ...
}
```

### Факторы стоимости

Итоговая стоимость закона зависит от:

#### 1. Базовая стоимость закона
```
dailyCost = baseCost × площадь_региона × коэффициент_сложности
```

#### 2. Тип политики
- **Постоянная политика**: `множитель = 1.0`
- **Временная политика**: `множитель = 2.0 - 3.0`

#### 3. Количество регионов
```
totalCost = sum(dailyCost_per_region) × количество_дней
```

#### 4. Эффективность закона
- **Постоянная политика**: `эффективность = 1.0`
- **Временная политика**: `эффективность = 2.0 - 3.0`

### Примеры расчета

#### Пример 1: Постоянная политика

**Закон**: "Субсидии на возобновляемую энергетику"
- Базовая стоимость: 1000 в день
- Тип: постоянная политика
- Регионов: 3
- Эффективность: 1.0

```
Стоимость = 1000 × 1.0 × 3 = 3000 в день
За 30 дней = 3000 × 30 = 90,000
```

#### Пример 2: Временная политика

**Закон**: "Субсидии на возобновляемую энергетику"
- Базовая стоимость: 1000 в день
- Тип: временная политика (множитель 2.5)
- Регионов: 3
- Длительность: 7 дней
- Эффективность: 2.5

```
Стоимость = 1000 × 2.5 × 3 = 7,500 в день
За 7 дней = 7,500 × 7 = 52,500
Эффект как от 132,500 (2.5× эффективнее)
```

## Каталог законов

### Категория: Экономика

#### 1. Налог на недвижимость (Property Tax)

**Описание**: Налог на жилую и коммерческую недвижимость

**Стоимость**: 0 в день (приносит доход)

**Параметры**:
- Ставка: 0.1% - 5.0% от стоимости
- Льготы по типу недвижимости
- Льготы по социальным группам

**Эффекты**:
```typescript
{
  budget: {
    income: +базовый_доход × ставка,
  },
  satisfaction: {
    residential: -5 × ставка,
    commercial: -3 × ставка,
  },
  migration: -2 × ставка,
}
```

**Взаимосвязь с системами**:
- **Система зданий**: считывает количество и стоимость зданий
- **Экономическая система**: начисляет доход в бюджет
- **Система населения**: снижает удовлетворение жителей

#### 2. Налог на бизнес (Business Tax)

**Описание**: Налог на прибыль коммерческих и промышленных предприятий

**Стоимость**: 0 в день (приносит доход)

**Параметры**:
- Ставка: 5% - 30% от прибыли
- Дифференциация по типам бизнеса
- Прогрессивная шкала

**Эффекты**:
```typescript
{
  budget: {
    income: +прибыль_предприятий × ставка,
  },
  satisfaction: {
    business: -10 × ставка,
  },
  construction: {
    commercial: -5 × ставка, // меньше строится
    industrial: -5 × ставка,
  },
  jobs: -2 × ставка, // меньше рабочих мест
}
```

**Взаимосвязь с системами**:
- **Экономическая система**: рассчитывает прибыль предприятий
- **Система зданий**: влияет на скорость строительства
- **Система населения**: влияет на занятость

#### 3. Субсидии на производство (Production Subsidies)

**Описание**: Финансовая поддержка производственных предприятий

**Стоимость**: 500 - 5000 в день (зависит от масштаба)

**Параметры**:
- Размер субсидии: 10% - 50% от расходов
- Целевые отрасли
- Условия получения

**Эффекты**:
```typescript
{
  budget: {
    expense: -размер_субсидии,
  },
  production: {
    efficiency: +15 × процент_субсидии,
    output: +10 × процент_субсидии,
  },
  jobs: +5,
  satisfaction: {
    business: +15,
    workers: +10,
  },
}
```

**Взаимосвязь с системами**:
- **Экономическая система**: выдает субсидии предприятиям
- **Система производства**: увеличивает эффективность
- **Система населения**: создает рабочие места

#### 4. Минимальная зарплата (Minimum Wage)

**Описание**: Законодательное установление минимального уровня оплаты труда

**Стоимость**: 100 - 1000 в день (контроль и надзор)

**Параметры**:
- Размер: 500 - 5000 в месяц
- Штрафы за нарушение
- Исключения (малый бизнес, стажеры)

**Эффекты**:
```typescript
{
  satisfaction: {
    workers: +20,
    lowIncome: +30,
    business: -15,
  },
  economy: {
    consumerSpending: +10,
    inflation: +5,
  },
  jobs: -5, // некоторые предприятия сокращают штат
  migration: +5, // привлекательность для рабочих
}
```

**Взаимосвязь с системами**:
- **Система населения**: устанавливает минимальный доход граждан
- **Экономическая система**: влияет на расходы предприятий
- **Система занятости**: может снизить количество рабочих мест

#### 5. Контроль цен (Price Control)

**Описание**: Ограничение цен на товары первой необходимости или аренду

**Стоимость**: 500 - 2000 в день (контроль и надзор)

**Параметры**:
- Категории товаров/услуг
- Максимальная цена/аренда
- Штрафы за нарушение

**Эффекты**:
```typescript
{
  satisfaction: {
    lowIncome: +25,
    middleClass: +10,
    business: -20,
  },
  economy: {
    supply: -15, // дефицит товаров
    blackMarket: +10, // рост черного рынка
  },
  construction: {
    residential: -10, // меньше строится
  },
}
```

**Взаимосвязь с системами**:
- **Экономическая система**: ограничивает ценообразование
- **Система торговли**: контролирует розничные цены
- **Система жилья**: контролирует аренду

### Категория: Градостроительство

#### 6. Зонирование (Zoning Regulations)

**Описание**: Определение разрешенных типов застройки в зонах

**Стоимость**: 200 - 1000 в день (планирование и контроль)

**Параметры**:
- Разрешенные типы (жилые, коммерческие, промышленные, смешанные)
- Ограничения (этажность, площадь)
- Требования (парковка, зеленые зоны)

**Эффекты**:
```typescript
{
  construction: {
    speed: -10, // дольше согласования
    cost: +5,
  },
  landValue: +10, // порядок повышает стоимость
  satisfaction: {
    residential: +15, // защита от промышленности
    business: -5, // ограничения
  },
  ecology: +5,
}
```

**Взаимосвязь с системами**:
- **Система зданий**: контролирует тип и параметры застройки
- **Система застройки**: определяет правила размещения
- **Редактор города**: ограничивает возможности игрока

#### 7. Ограничение высотности (Height Restrictions)

**Описание**: Максимальная этажность зданий в зоне

**Стоимость**: 100 - 500 в день

**Параметры**:
- Максимальная высота: 3-50 этажей
- Исключения (особые зоны)
- Требования к небоскребам

**Эффекты**:
```typescript
{
  construction: {
    maxFloors: установленный_лимит,
    density: -10 × (ограничение / 50),
  },
  satisfaction: {
    residential: +10, // больше света
  },
  landValue: +5, // престиж низкой застройки
  capacity: -15, // меньше населения/бизнеса
}
```

**Взаимосвязь с системами**:
- **Система зданий**: ограничивает высоту при строительстве
- **Система населения**: влияет на плотность населения
- **Визуализация**: ограничивает 3D-модели

#### 8. Требования к парковке (Parking Requirements)

**Описание**: Обязательное количество парковочных мест на здание

**Стоимость**: 200 - 800 в день (контроль)

**Параметры**:
- Мест на жилую единицу: 0.5 - 2.0
- Мест на коммерческую площадь: 1 на 50-200 м²
- Исключения (центр города, станции метро)

**Эффекты**:
```typescript
{
  construction: {
    cost: +10 × коэффициент,
    speed: -5,
  },
  traffic: {
    parking: +20, // больше мест
    congestion: -5, // меньше ищущих парковку
  },
  satisfaction: {
    carOwners: +15,
    business: -10, // дороже строить
  },
}
```

**Взаимосвязь с системами**:
- **Система зданий**: добавляет парковки к зданиям
- **Транспортная система**: учитывает парковочные места
- **Система строительства**: увеличивает стоимость

#### 9. Зеленые зоны (Green Space Requirements)

**Описание**: Минимальный процент зеленых насаждений

**Стоимость**: 300 - 1500 в день (контроль и озеленение)

**Параметры**:
- Процент зеленых зон: 10% - 40%
- Типы насаждений (деревья, парки, газоны)
- Требования к уходу

**Эффекты**:
```typescript
{
  construction: {
    cost: +5 × процент / 10,
    usableArea: -процент,
  },
  ecology: {
    airPollution: -15 × процент / 10,
    noise: -10 × процент / 10,
  },
  satisfaction: {
    residential: +20 × процент / 10,
  },
  health: +10 × процент / 10,
}
```

**Взаимосвязь с системами**:
- **Система застройки**: резервирует места под зелень
- **Экологическая система**: улучшает показатели
- **Система здравоохранения**: снижает заболеваемость

#### 10. Историческое наследие (Historic Preservation)

**Описание**: Защита исторических зданий от сноса/изменения

**Стоимость**: 500 - 2000 в день (охрана, реставрация)

**Параметры**:
- Охраняемые здания
- Требования к реставрации
- Субсидии на поддержание

**Эффекты**:
```typescript
{
  construction: {
    demolition: false, // запрет сноса
    renovation: {
      cost: +50,
      restrictions: высокие,
    },
  },
  tourism: +20,
  culture: +15,
  satisfaction: {
    culturalElite: +25,
    developers: -20,
  },
  landValue: +10, // престиж истории
}
```

**Взаимосвязь с системами**:
- **Система зданий**: защищает от сноса
- **Туристическая система**: увеличивает привлекательность
- **Культурная система**: сохраняет наследие

### Категория: Транспорт

#### 11. Ограничение скорости (Speed Limits)

**Описание**: Установление максимальной скорости на дорогах

**Стоимость**: 100 - 500 в день (контроль, камеры)

**Параметры**:
- Скорость по типам дорог: 20 - 130 км/ч
- Зоны ограничения (школы, жилые районы)
- Штрафы за нарушение

**Эффекты**:
```typescript
{
  traffic: {
    speed: установленный_лимит,
    throughput: -5 × (снижение / 10), // меньше пропускная способность
  },
  safety: {
    accidents: -20 × (снижение / 10),
    deaths: -30 × (снижение / 10),
  },
  satisfaction: {
    residents: +10, // тише и безопаснее
    drivers: -5, // медленнее
  },
}
```

**Взаимосвязь с системами**:
- **Транспортная система**: ограничивает скорость ТС
- **Система ПДД**: контролирует соблюдение
- **Система безопасности**: снижает аварийность

#### 12. Платные дороги (Toll Roads)

**Описание**: Взимание платы за проезд по определенным дорогам

**Стоимость**: 200 - 1000 в день (содержание пунктов оплаты)

**Параметры**:
- Тариф: 1 - 50 за проезд
- Дороги/зоны
- Льготы (жители, ОТ, экстренные службы)

**Эффекты**:
```typescript
{
  budget: {
    income: +количество_проездов × тариф,
  },
  traffic: {
    volume: -15, // меньше трафика
    alternativeRoutes: +20, // объездные дороги
  },
  satisfaction: {
    drivers: -15,
    residents: +5, // меньше транзита
  },
}
```

**Взаимосвязь с системами**:
- **Транспортная система**: взимает плату с ТС
- **Экономическая система**: пополняет бюджет
- **Система маршрутизации**: учитывает стоимость в расчетах

#### 13. Приоритет ОТ (Public Transport Priority)

**Описание**: Выделенные полосы и преимущества для общественного транспорта

**Стоимость**: 500 - 2000 в день (инфраструктура, контроль)

**Параметры**:
- Выделенные полосы
- Приоритет на светофорах
- Штрафы за нарушение

**Эффекты**:
```typescript
{
  publicTransport: {
    speed: +30,
    punctuality: +25,
    attractiveness: +20,
  },
  traffic: {
    carLanes: -1, // меньше полос для авто
    congestion: +10 × (1 - использование_ОТ / 100),
  },
  satisfaction: {
    ptUsers: +20,
    carOwners: -10,
  },
  ecology: {
    emissions: -10,
  },
}
```

**Взаимосвязь с системами**:
- **Транспортная система**: увеличивает скорость ОТ
- **Система маршрутизации**: приоритет в расчетах
- **Система дорог**: выделяет полосы

#### 14. Экологические зоны (Low Emission Zones)

**Описание**: Ограничение въезда старых/грязных автомобилей

**Стоимость**: 300 - 1500 в день (контроль)

**Параметры**:
- Экологический класс: Евро-3 и выше
- Зоны действия
- Штрафы/пропуски

**Эффекты**:
```typescript
{
  traffic: {
    volume: -20, // часть авто не может въехать
  },
  ecology: {
    airPollution: -25,
    emissions: -30,
  },
  satisfaction: {
    ecoConscious: +25,
    oldCarOwners: -30,
    residents: +15, // чище воздух
  },
  economy: {
    carReplacement: +10, // покупка новых авто
  },
}
```

**Взаимосвязь с системами**:
- **Транспортная система**: фильтрует ТС по экологическому классу
- **Экологическая система**: снижает выбросы
- **Экономическая система**: стимулирует обновление автопарка

#### 15. Парковочные тарифы (Parking Fees)

**Описание**: Оплата парковки в определенных зонах

**Стоимость**: 100 - 800 в день (паркоматы, контроль)

**Параметры**:
- Тариф: 10 - 500 за час
- Зоны (центр дороже)
- Льготы (жители, инвалиды)

**Эффекты**:
```typescript
{
  budget: {
    income: +количество_парковок × средний_тариф × часы,
  },
  traffic: {
    parkingSearch: -20, // быстрее находят место
    carUsage: -10 × (тариф / 100), // меньше используют авто
  },
  satisfaction: {
    carOwners: -15 × (тариф / 100),
    ptUsers: +5,
    residents: +10, // меньше парковок на газонах
  },
}
```

**Взаимосвязь с системами**:
- **Транспортная система**: управляет парковками
- **Экономическая система**: собирает оплату
- **Система населения**: влияет на выбор транспорта

### Категория: Экология

#### 16. Лимиты на выбросы (Emission Limits)

**Описание**: Ограничение промышленных выбросов в атмосферу

**Стоимость**: 500 - 3000 в день (мониторинг, контроль)

**Параметры**:
- Лимит выбросов: тонн CO₂/год
- По типам предприятий
- Штрафы за превышение

**Эффекты**:
```typescript
{
  ecology: {
    airPollution: -30,
    emissions: -40,
  },
  industry: {
    cost: +15, // расходы на фильтры
    production: -5, // снижение из-за ограничений
  },
  satisfaction: {
    residents: +20,
    ecoConscious: +30,
    industrialists: -25,
  },
  health: +15,
}
```

**Взаимосвязь с системами**:
- **Экологическая система**: ограничивает выбросы предприятий

## Механика применения

### Процесс создания политики

```typescript
interface PolicyCreation {
  // 1. Выбор типа
  type: 'permanent' | 'temporary';
  
  // 2. Выбор законов (3-5 для временных, любое для постоянных)
  laws: Law[];
  
  // 3. Настройка параметров законов
  lawSettings: {
    [lawId: string]: LawParameters;
  };
  
  // 4. Для временных: установка длительности
  duration?: number; // дни (3-30)
  
  // 5. Выбор регионов применения
  regions: RegionId[];
  
  // 6. Расчет стоимости
  totalCost: number;
  dailyCost: number;
  
  // 7. Подтверждение
  confirmation: boolean;
}
```

### Расчет эффектов

```typescript
function calculatePolicyEffects(policy: Policy): Effects {
  let effects = {};
  
  for (const law of policy.laws) {
    const lawEffects = law.effects;
    const multiplier = policy.type === 'temporary' 
      ? law.temporaryMultiplier 
      : 1.0;
    
    // Применяем множитель
    const scaledEffects = scaleEffects(lawEffects, multiplier);
    
    // Суммируем эффекты
    effects = mergeEffects(effects, scaledEffects);
  }
  
  // Учитываем взаимодействия между законами
  effects = applyLawInteractions(effects, policy.laws);
  
  return effects;
}
```

### Применение к регионам

```typescript
function applyPolicyToRegions(policy: Policy, regions: Region[]) {
  for (const region of regions) {
    // Применяем эффекты
    region.applyEffects(policy.effects);
    
    // Добавляем в активные политики
    region.activePolicies.push(policy);
    
    // Начисляем стоимость
    region.dailyCosts += policy.dailyCost / regions.length;
    
    // Уведомляем системы
    notifySystems(region, policy);
  }
}
```

### Конфликты законов

Некоторые законы конфликтуют между собой:

```typescript
const lawConflicts = {
  'low-taxes': ['high-welfare', 'free-education'],
  'strict-zoning': ['fast-development'],
  'car-priority': ['public-transport-priority'],
  // ...
};

function checkConflicts(laws: Law[]): Conflict[] {
  const conflicts = [];
  
  for (const law1 of laws) {
    for (const law2 of laws) {
      if (lawConflicts[law1.id]?.includes(law2.id)) {
        conflicts.push({ law1, law2 });
      }
    }
  }
  
  return conflicts;
}
```

### Пример интеграции: Налог на недвижимость

```typescript
// В Economic System
class PropertyTaxCollector {
  collectTaxes(region: Region) {
    // Получаем закон из активных политик
    const taxLaw = region.getActiveLaw('property-tax');
    if (!taxLaw) return;
    
    // Получаем все здания
    const buildings = buildingSystem.getBuildings(region);
    
    let totalTax = 0;
    for (const building of buildings) {
      // Рассчитываем налог
      const value = building.getValue();
      const rate = taxLaw.parameters.rate;
      const tax = value * rate;
      
      // Применяем льготы
      const exemptions = taxLaw.parameters.exemptions;
      const finalTax = applyExemptions(tax, building, exemptions);
      
      totalTax += finalTax;
      
      // Снижаем удовлетворение владельцев
      populationSystem.modifySatisfaction(
        building.owners, 
        -5 * rate
      );
    }
    
    // Пополняем бюджет
    budgetSystem.addIncome(region, totalTax, 'property-tax');
  }
}
```

### Пример интеграции: Приоритет ОТ

```typescript
// В Transport System
class TrafficController {
  calculateSpeed(vehicle: Vehicle, road: Road) {
    let speed = vehicle.maxSpeed;
    
    // Проверяем законы региона
    const region = road.region;
    const priorityLaw = region.getActiveLaw('public-transport-priority');
    
    if (priorityLaw && vehicle.type === 'publicTransport') {
      // ОТ получает приоритет
      speed *= 1.3; // +30%
      
      // Проверяем выделенные полосы
      if (road.hasLane('bus')) {
        speed *= 1.2; // еще +20%
      }
    } else if (priorityLaw && road.hasLane('bus')) {
      // Личный транспорт теряет полосу
      speed *= 0.9; // -10%
    }
    
    return speed;
  }
}
```
