## Концепция системы

### Иерархия

```
Политика (Policy)
  ├─ Закон 1 (Law)
  ├─ Закон 2 (Law)
  ├─ Закон 3 (Law)
  └─ Закон N (Law)
```

### Определения

- **Закон (Law)** — атомарное правило, влияющее на один аспект игры
- **Политика (Policy)** — набор законов, объединенных общей целью
- **Временная политика (Temporary Policy)** — краткосрочная политика для событий
- **Регион** — территория, к которой применяются политики

## Типы политик

### 1. Постоянные политики (Permanent Policies)

**Характеристики:**
- Действуют бессрочно до отмены
- Стандартная стоимость законов
- Постепенное накопление эффектов
- Влияют на долгосрочное развитие

**Примеры:**
- "Зеленый город"
- "Деловой центр"
- "Социальный район"

### 2. Временные политики (Temporary Policies)

**Характеристики:**
- Действуют ограниченное время (от 3 до 30 дней)
- Стоимость законов **в 2-3 раза выше**
- Эффективность законов **в 2-3 раза выше**
- Быстрый, но дорогой эффект

**Применение:**
- Акции и мероприятия
- Праздники (Новый год, национальные праздники)
- Кризисные ситуации (выборы, происшествия)
- Сезонные события

**Механика создания:**
1. Игрок выбирает 3-5 законов из каталога
2. Устанавливает длительность (3-30 дней)
3. Система рассчитывает стоимость с учетом множителей
4. Политика применяется к выбранным регионам

**Примеры:**
- "Новогодняя ярмарка" (14 дней)
- "Неделя экологии" (7 дней)
- "Предвыборная кампания" (30 дней)
- "Антикризисная программа" (до 30 дней)

## Стоимость законов

### Базовая стоимость

Каждый закон имеет **стоимость в день** (daily cost):

```typescript
interface Law {
  id: string;
  name: string;
  dailyCost: number; // в игровой валюте
  effects: Effect[];
  // ...
}
```

### Факторы стоимости

Итоговая стоимость закона зависит от:

#### 1. Базовая стоимость закона
```
dailyCost = baseCost × площадь_региона × коэффициент_сложности
```

#### 2. Тип политики
- **Постоянная политика**: `множитель = 1.0`
- **Временная политика**: `множитель = 2.0 - 3.0`

#### 3. Количество регионов
```
totalCost = sum(dailyCost_per_region) × количество_дней
```

#### 4. Эффективность закона
- **Постоянная политика**: `эффективность = 1.0`
- **Временная политика**: `эффективность = 2.0 - 3.0`

### Примеры расчета

#### Пример 1: Постоянная политика

**Закон**: "Субсидии на возобновляемую энергетику"
- Базовая стоимость: 1000 в день
- Тип: постоянная политика
- Регионов: 3
- Эффективность: 1.0

```
Стоимость = 1000 × 1.0 × 3 = 3000 в день
За 30 дней = 3000 × 30 = 90,000
```

#### Пример 2: Временная политика

**Закон**: "Субсидии на возобновляемую энергетику"
- Базовая стоимость: 1000 в день
- Тип: временная политика (множитель 2.5)
- Регионов: 3
- Длительность: 7 дней
- Эффективность: 2.5

```
Стоимость = 1000 × 2.5 × 3 = 7,500 в день
За 7 дней = 7,500 × 7 = 52,500
Эффект как от 132,500 (2.5× эффективнее)
```

## Система привлекательности

### Концепция

**Привлекательность (Attractiveness)** — один из важнейших параметров региона, определяющий:

1. **Количество клиентов** для коммерческих зон
2. **Стоимость земли** (land value)
3. **Миграцию населения** (приток/отток)
4. **Скорость развития** зон
5. **Инвестиционную привлекательность**

### Базовая формула

```typescript
interface Attractiveness {
  base: number;           // Базовая привлекательность (50-100)
  taxModifier: number;    // Модификатор от налогов (-50 до +50)
  infrastructure: number; // Инфраструктура (0-30)
  ecology: number;        // Экология (0-20)
  safety: number;         // Безопасность (0-15)
  services: number;       // Услуги (0-15)
  policies: number;       // Эффекты политик (0-20)
  
  total: number;          // Итоговая привлекательность (0-250)
}
```

### Расчет итоговой привлекательности

```typescript
totalAttractiveness = base 
  + taxModifier 
  + infrastructure 
  + ecology 
  + safety 
  + services 
  + policies
```

**Диапазоны:**
- **0-50**: Очень низкая (депрессивный регион)
- **51-100**: Низкая (требует развития)
- **101-150**: Средняя (нормальное развитие)
- **151-200**: Высокая (привлекательный регион)
- **201-250**: Очень высокая (премиум регион)

### Влияние налогов на привлекательность

#### Механика

**Высокие налоги снижают привлекательность, низкие — увеличивают.**

```typescript
function calculateTaxModifier(taxes: TaxRates): number {
  // Базовый модификатор (0 при средних налогах)
  let modifier = 0;
  
  // Налог на недвижимость
  const propertyTaxRate = taxes.property; // 0.1% - 5.0%
  const propertyTaxBase = 1.5; // средняя ставка
  modifier -= (propertyTaxRate - propertyTaxBase) × 20;
  
  // Налог на бизнес
  const businessTaxRate = taxes.business; // 5% - 30%
  const businessTaxBase = 15; // средняя ставка
  modifier -= (businessTaxRate - businessTaxBase) × 1.5;
  
  // Ограничиваем диапазон
  return clamp(modifier, -50, +50);
}
```

#### Примеры расчета

**Сценарий 1: Низкие налоги**
- Налог на недвижимость: 0.5% (база 1.5%)
- Налог на бизнес: 8% (база 15%)
- Модификатор: `-((0.5-1.5)×20) - ((8-15)×1.5) = +20 + 10.5 = +30.5`
- **Привлекательность**: +30.5

**Сценарий 2: Средние налоги**
- Налог на недвижимость: 1.5% (база 1.5%)
- Налог на бизнес: 15% (база 15%)
- Модификатор: `-((1.5-1.5)×20) - ((15-15)×1.5) = 0`
- **Привлекательность**: 0 (нейтрально)

**Сценарий 3: Высокие налоги**
- Налог на недвижимость: 4.0% (база 1.5%)
- Налог на бизнес: 25% (база 15%)
- Модификатор: `-((4.0-1.5)×20) - ((25-15)×1.5) = -50 - 15 = -65` → `-50` (ограничение)
- **Привлекательность**: -50 (максимальный штраф)

### Баланс по зонам

#### 1. Жилые зоны (Residential)

**Влияние привлекательности:**

```typescript
interface ResidentialAttractiveness {
  // Количество желающих переехать
  migration: attractiveness × 2; // +2 мигранта на единицу привлекательности
  
  // Стоимость земли
  landValue: baseValue × (1 + attractiveness / 100);
  
  // Скорость застройки
  constructionSpeed: baseSpeed × (1 + attractiveness / 200);
  
  // Качество жилья (автоматическая застройка)
  buildingQuality: min(10, 5 + attractiveness / 25);
}
```

**Ключевые факторы:**
- **Низкие налоги** → больше желающих переехать
- **Высокие налоги** → отток населения
- **Инфраструктура** → доступность услуг
- **Экология** → качество жизни
- **Безопасность** → спокойствие жителей

**Баланс:**
- Привлекательность 100-120: нормальная застройка
- Привлекательность 120-150: быстрая застройка, качественные здания
- Привлекательность 150+: премиум застройка, высокая стоимость земли
- Привлекательность <80: медленная застройка, дешевая земля, отток населения

#### 2. Коммерческие зоны (Commercial)

**Влияние привлекательности:**

```typescript
interface CommercialAttractiveness {
  // Количество клиентов
  clientCount: baseClients × (1 + attractiveness / 100);
  
  // Стоимость земли
  landValue: baseValue × (1 + attractiveness / 80);
  
  // Доходность бизнеса
  profitability: baseProfit × (1 + attractiveness / 120);
  
  // Разнообразие бизнеса
  businessDiversity: min(10, 3 + attractiveness / 20);
}
```

**Ключевые факторы:**
- **Низкие налоги на бизнес** → больше предпринимателей
- **Высокие налоги** → закрытие бизнесов, меньше клиентов
- **Транспортная доступность** → поток клиентов
- **Безопасность** → комфорт посещения
- **Соседние зоны** → жилые зоны = клиенты

**Баланс:**
- Привлекательность 100-120: базовый поток клиентов
- Привлекательность 120-150: высокий поток, разнообразие бизнеса
- Привлекательность 150+: премиум бизнес, высокая прибыльность
- Привлекательность <80: мало клиентов, закрытие магазинов

**Формула клиентов:**
```
клиенты_в_день = базовая_популярность × (1 + привлекательность/100) × доступность_транспорта × безопасность
```

#### 3. Промышленные зоны (Industrial)

**Влияние привлекательности:**

```typescript
interface IndustrialAttractiveness {
  // Количество предприятий
  factoryCount: baseFactories × (1 + attractiveness / 120);
  
  // Стоимость земли
  landValue: baseValue × (1 + attractiveness / 150);
  
  // Эффективность производства
  productionEfficiency: baseEfficiency × (1 + attractiveness / 200);
  
  // Инвестиции в модернизацию
  modernization: attractiveness > 120 ? +10 : 0;
}
```

**Ключевые факторы:**
- **Низкие налоги на бизнес** → больше инвестиций
- **Высокие налоги** → закрытие заводов, уход инвесторов
- **Транспортная доступность** → логистика
- **Экологические ограничения** → могут снижать привлекательность для "грязных" производств
- **Наличие ресурсов** → сырье

**Баланс:**
- Привлекательность 100-120: нормальное производство
- Привлекательность 120-150: высокотехнологичные производства
- Привлекательность 150+: инновационные производства, высокая эффективность
- Привлекательность <80: устаревшие производства, низкая эффективность

**Особенность:**
- Промышленные зоны менее чувствительны к общей привлекательности
- Важнее: налоги, логистика, ресурсы
- Экология может снижать привлекательность для жителей, но не для производства

### Баланс по производствам

#### Влияние привлекательности на производство

```typescript
interface ProductionAttractiveness {
  // Производительность
  output: baseOutput × (1 + attractiveness / 150);
  
  // Качество продукции
  quality: baseQuality × (1 + attractiveness / 200);
  
  // Инновации
  innovation: attractiveness > 130 ? +15 : 0;
  
  // Стоимость производства
  cost: baseCost × (1 - attractiveness / 300); // ниже при высокой привлекательности
}
```

**Типы производств:**

1. **Традиционные производства** (низкая чувствительность)
   - Заводы, фабрики
   - Зависимость от привлекательности: низкая
   - Важнее: налоги, логистика, ресурсы

2. **Высокотехнологичные производства** (высокая чувствительность)
   - IT-компании, НИОКР
   - Зависимость от привлекательности: высокая
   - Требуют: высокую привлекательность (150+), низкие налоги, хорошую инфраструктуру

3. **Сервисные производства** (средняя чувствительность)
   - Услуги, торговля
   - Зависимость от привлекательности: средняя
   - Требуют: клиентов, доступность, безопасность

### Интеграция с системами

```typescript
// В Economic System
class AttractivenessSystem {
  calculateAttractiveness(region: Region): number {
    let attractiveness = region.baseAttractiveness;
    
    // Налоги
    const taxModifier = this.calculateTaxModifier(region.taxes);
    attractiveness += taxModifier;
    
    // Инфраструктура
    attractiveness += this.calculateInfrastructureBonus(region);
    
    // Экология
    attractiveness += this.calculateEcologyBonus(region);
    
    // Безопасность
    attractiveness += this.calculateSafetyBonus(region);
    
    // Услуги
    attractiveness += this.calculateServicesBonus(region);
    
    // Политики
    attractiveness += this.calculatePoliciesBonus(region);
    
    return clamp(attractiveness, 0, 250);
  }
  
  applyAttractivenessEffects(region: Region, attractiveness: number) {
    // Влияние на стоимость земли
    region.landValue = region.baseLandValue * (1 + attractiveness / 100);
    
    // Влияние на клиентов (коммерческие зоны)
    region.commercialZones.forEach(zone => {
      zone.clientCount = zone.baseClientCount * (1 + attractiveness / 100);
    });
    
    // Влияние на миграцию (жилые зоны)
    region.migrationRate = attractiveness * 2; // +2 мигранта на единицу
    
    // Влияние на производство
    region.productionEfficiency = 1 + (attractiveness / 150);
  }
}
```

## Каталог законов

### Категория: Экономика

#### 1. Налог на недвижимость (Property Tax)

**Описание**: Налог на жилую и коммерческую недвижимость

**Стоимость**: 0 в день (приносит доход)

**Параметры**:
- Ставка: 0.1% - 5.0% от стоимости
- Льготы по типу недвижимости
- Льготы по социальным группам

**Эффекты**:
```typescript
{
  budget: {
    income: +базовый_доход × ставка,
  },
  satisfaction: {
    residential: -5 × ставка,
    commercial: -3 × ставка,
  },
  migration: -2 × ставка,
  attractiveness: {
    residential: -20 × (ставка - 1.5) / 1.5, // базовая ставка 1.5%
    commercial: -15 × (ставка - 1.5) / 1.5,
```

## Механика применения

### Процесс создания политики

```typescript
interface PolicyCreation {
  // 1. Выбор типа
  type: 'permanent' | 'temporary';
  
  // 2. Выбор законов (3-5 для временных, любое для постоянных)
  laws: Law[];
  
  // 3. Настройка параметров законов
  lawSettings: {
    [lawId: string]: LawParameters;
  };
  
  // 4. Для временных: установка длительности
  duration?: number; // дни (3-30)
  
  // 5. Выбор регионов применения
  regions: RegionId[];
  
  // 6. Расчет стоимости
  totalCost: number;
  dailyCost: number;
  
  // 7. Подтверждение
  confirmation: boolean;
}
```

### Расчет эффектов

```typescript
function calculatePolicyEffects(policy: Policy): Effects {
  let effects = {};
  
  for (const law of policy.laws) {
    const lawEffects = law.effects;
    const multiplier = policy.type === 'temporary' 
      ? law.temporaryMultiplier 
      : 1.0;
    
    // Применяем множитель
    const scaledEffects = scaleEffects(lawEffects, multiplier);
    
    // Суммируем эффекты
    effects = mergeEffects(effects, scaledEffects);
  }
  
  // Учитываем взаимодействия между законами
  effects = applyLawInteractions(effects, policy.laws);
  
  return effects;
}
```

### Применение к регионам

```typescript
function applyPolicyToRegions(policy: Policy, regions: Region[]) {
  for (const region of regions) {
    // Применяем эффекты
    region.applyEffects(policy.effects);
    
    // Добавляем в активные политики
    region.activePolicies.push(policy);
    
    // Начисляем стоимость
    region.dailyCosts += policy.dailyCost / regions.length;
    
    // Уведомляем системы
    notifySystems(region, policy);
  }
}
```

### Конфликты законов

Некоторые законы конфликтуют между собой:

```typescript
const lawConflicts = {
  'low-taxes': ['high-welfare', 'free-education'],
  'strict-zoning': ['fast-development'],
  'car-priority': ['public-transport-priority'],
  // ...
};

function checkConflicts(laws: Law[]): Conflict[] {
  const conflicts = [];
  
  for (const law1 of laws) {
    for (const law2 of laws) {
      if (lawConflicts[law1.id]?.includes(law2.id)) {
        conflicts.push({ law1, law2 });
      }
    }
  }
  
  return conflicts;
}
```

### Пример интеграции: Налог на недвижимость

```typescript
// В Economic System
class PropertyTaxCollector {
  collectTaxes(region: Region) {
    // Получаем закон из активных политик
    const taxLaw = region.getActiveLaw('property-tax');
    if (!taxLaw) return;
    
    // Получаем все здания
    const buildings = buildingSystem.getBuildings(region);
    
    let totalTax = 0;
    for (const building of buildings) {
      // Рассчитываем налог
      const value = building.getValue();
      const rate = taxLaw.parameters.rate;
      const tax = value * rate;
      
      // Применяем льготы
      const exemptions = taxLaw.parameters.exemptions;
      const finalTax = applyExemptions(tax, building, exemptions);
      
      totalTax += finalTax;
      
      // Снижаем удовлетворение владельцев
      populationSystem.modifySatisfaction(
        building.owners, 
        -5 * rate
      );
    }
    
    // Пополняем бюджет
    budgetSystem.addIncome(region, totalTax, 'property-tax');
  }
}
```

### Пример интеграции: Приоритет ОТ

```typescript
// В Transport System
class TrafficController {
  calculateSpeed(vehicle: Vehicle, road: Road) {
    let speed = vehicle.maxSpeed;
    
    // Проверяем законы региона
    const region = road.region;
    const priorityLaw = region.getActiveLaw('public-transport-priority');
    
    if (priorityLaw && vehicle.type === 'publicTransport') {
      // ОТ получает приоритет
      speed *= 1.3; // +30%
      
      // Проверяем выделенные полосы
      if (road.hasLane('bus')) {
        speed *= 1.2; // еще +20%
      }
    } else if (priorityLaw && road.hasLane('bus')) {
      // Личный транспорт теряет полосу
      speed *= 0.9; // -10%
    }
    
    return speed;
  }
}
```
