# Туториалы Script City

**Теги**: `guide:tutorial`, `guide:developer-onboarding`

Эта папка содержит пошаговые руководства и туториалы для разработчиков Script City.

## Доступные туториалы

### 🎯 Для новичков

- **[Как работает ядро на примере модулей](./how-core-works-by-modules-example.md)** — подробный разбор работы игрового ядра через реальные примеры:
  - `DebugModule` — отладочная информация
  - `BottomBarModule` — управление временем игры
  - `SpeedIndicatorModule` — визуальный индикатор скорости

  **Что вы узнаете**:
  - Зачем нужны компоненты ядра (GameCore, ModuleManager, EventBus, TickManager и т.д.)
  - Как работает жизненный цикл от создания ядра до работы модулей
  - Паттерны взаимодействия модулей с ядром
  - Как создать свой модуль с нуля

- **[Как использовать ECS (Entity Component System)](./how-to-use-ecs.md)** — практическое руководство по работе с ECS:
  - Создание сущностей (entities)
  - Создание и использование компонентов (components)
  - Создание и регистрация систем (systems)
  - Полные примеры кода

  **Что вы узнаете**:
  - Как создавать сущности и добавлять к ним компоненты
  - Как создавать системы для обработки игровой логики
  - Как организовать код с использованием ECS
  - Примеры реальных систем (движение, здоровье, здания)

## Как пользоваться туториалами

1. **Начните с основ** — прочитайте [Как работает ядро на примере модулей](./how-core-works-by-modules-example.md)
2. **Изучите примеры кода** — все примеры взяты из реального кода проекта
3. **Попробуйте сами** — создайте свой модуль по чеклисту из туториала
4. **Задавайте вопросы** — если что-то непонятно, создайте Issue на GitHub

## Добавление новых туториалов

Если вы хотите добавить новый туториал:

1. Создайте markdown файл в этой папке
2. Используйте теги `guide:tutorial` и другие релевантные теги
3. Следуйте структуре существующих туториалов
4. Добавьте ссылку в этот README
5. Обновите главный [README документации](../README.md)
