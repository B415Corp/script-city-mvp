# Технический стек

Последнее обновление: 2025-11-11

## Frontend

### Основные технологии

- **React 18+** - библиотека для построения UI
- **TypeScript** - строгая типизация
- **Vite** - сборщик и dev-сервер

### Управление состоянием

- **Redux Toolkit** - управление глобальным состоянием
- **RTK Query** - работа с API и кэширование

### Маршрутизация

- **React Router** - клиентская маршрутизация

### Формы и валидация

- **React Hook Form** - работа с формами
- **Zod** - валидация схем

### Стилизация

- **Tailwind CSS** - utility-first CSS фреймворк

### Иконки

- **Lucide Icons** - набор иконок

### Тестирование

- **Vitest** - тестовый фреймворк
- **@testing-library/react** - тестирование React компонентов

## Архитектура

- **Feature-Sliced Design (FSD)** - методология организации кода

## Инструменты разработки

- **ESLint** - линтер
- **Prettier** - форматирование кода
- **TypeScript** - проверка типов

## Производительность

- **Web Workers** - для тяжёлых вычислений (симуляция, маршрутизация)
- **Инкрементальные обновления** - оптимизация пересчётов

## Планируемые технологии (Post-MVP)

- **WebGL/Three.js** - для продвинутой 3D визуализации (опционально)
- **WebAssembly** - для критичных вычислений (опционально)
