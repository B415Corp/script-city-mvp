# UI-слой

**Теги**: `arch:ui`, `arch:commands`, `gameplay:time-control`

UI-слой строится без React и представляет собой:

- **HUD и панели**:
  - информация о бюджете, населении, политике;
  - кнопки режимов, скорости времени, выбора инструментов.
- **Окна и диалоги**:
  - свойства зданий;
  - лог событий;
  - настройки.

## Правила

- UI не хранит `GameState`.
- Любое действие игрока = отправка **команды** ядру (например, `BuildBuilding`, `Bulldoze`, `ChangeTax`).
- UI подписывается на **агрегированные данные** и события (например, текущий бюджет, статусы модулей), а не на сырые структуры ECS.
