# Дальнейшее развитие

В следующих версиях:

- вынос авторитетной симуляции на сервер (Node.js / FastAPI);
- полноценный мультиплеер с синхронизацией состояний;
- расширение моделей (население, транспорт, инфраструктура, политики);
- импорт реальных карт (OpenStreetMap);
- машинное обучение для ИИ агентов;
- процедурная генерация городов;
- инструменты моддинга и внешние API.
