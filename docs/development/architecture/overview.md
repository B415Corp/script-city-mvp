# Обзор архитектуры

## Высокоуровневая схема

- **Игровое ядро (Core)**:
  - центральная точка запуска и координации;
  - цикл тиков (game loop);
  - менеджеры ECS, событий, модулей.
- **Модули симуляции**:
  - транспорт, экономика, население, здания, инфраструктура, политики и др.;
  - каждый модуль регистрирует свои компоненты и системы в ядре.
- **Слой представления (Renderer)**:
  - PixiJS-сцены, спрайты, тайловая карта, эффекты;
  - работает поверх данных компонентов (позиция, состояние).
- **UI-слой**:
  - меню, панели, HUD без React;
  - взаимодействует с ядром через команды и агрегированные данные.
- **Инфраструктурные сервисы поверх PixiJS**:
  - изометрическая математика;
  - менеджер чанков карты;
  - рендерер тайлов и объектов;
  - модель `GameWorld`;
  - задел под слой синхронизации с сервером.
