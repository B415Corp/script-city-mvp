# Инфраструктурные сервисы поверх Phaser

Эти сервисы обеспечивают основу для работы с картой и рендером.

## `IsometricMath`

Назначение:

- конвертация координат **тайлов** в экранные координаты и обратно:
  - `tileToScreen(tileX, tileY) → { x, y }`;
  - `screenToTile(screenX, screenY) → { tileX, tileY }`.
- учёт:
  - размеров тайла;
  - смещений камеры;
  - изометрической проекции.

## `ChunkManager`

Назначение:

- деление карты на **чанки** (например, 64×64 тайлов);
- определение, какие чанки сейчас находятся в зоне видимости камеры;
- загрузка/выгрузка чанков:
  - и на уровне данных (`GameWorld`),
  - и на уровне рендера (спрайты в Phaser).

## `TileRenderer`

Назначение:

- создание спрайтов для тайлов и объектов;
- обновление спрайтов при изменении компонентов (тип, состояние, текстуры);
- удаление спрайтов, когда чанки выгружаются или объекты исчезают.

## `GameWorld`

Назначение:

- модель состояния мира, независимая от UI и транспорта:
  - тайлы и их параметры;
  - здания, дороги, объекты;
  - связи с компонентами ECS.
- требования:
  - сериализуемость (для сохранений и передачи на сервер);
  - возможность частичной загрузки (по чанкам).

## Слой синхронизации

В будущем:

- абстракция, через которую ядро и `GameWorld` могут:
  - работать **локально** (один процесс, без сети);
  - или через **сервер** (WebSocket, Socket.io).
- интерфейс не зависит от конкретного транспорта:
  - команды (`Command`) и снапшоты/патчи состояния.
