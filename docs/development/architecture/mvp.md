# Минимальное ядро (MVP) и модульные расширения

## Минимальное ядро (MVP)

Состав:

- управление временем и тиками;
- базовая ECS:
  - реестр сущностей (Entity registry);
  - хранилище компонентов (Components store);
  - раннер систем (Systems runner);
- базовый набор компонентов:
  - позиция;
  - визуальное представление;
  - параметры базовых зданий;
- карта:
  - простое тайловое поле (сразу с поддержкой чанков);
  - базовый рендер на PixiJS.

## Минимальные модули для старта

1. **Модуль "Здания"**:
   - базовые типы зданий (жилые/коммерческие/промышленные);
   - логика постройки и сноса;
   - события: начало/завершение строительства.
2. **Модуль "Экономика (упрощённая)"**:
   - доходы/расходы города;
   - привязка к зданиям (налоги, обслуживание).
3. **Модуль "Городская карта"**:
   - управление чанками;
   - связь с `ChunkManager` и `TileRenderer`;
   - загрузка/выгрузка данных по мере движения камеры.

Дальнейшие модули (население, транспорт, инфраструктура, политики) добавляются **поверх** этого ядра без его переписывания.
