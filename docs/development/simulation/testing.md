# Тестирование симуляции

Рекомендуется:

## Модульные тесты

- покрывать модульными тестами:
  - отдельные системы ECS (экономика, население, транспорт);
  - обработчики команд (валидность, эффекты).

## Сценарные тесты

- писать сценарные тесты:
  - несколько тиков подряд;
  - проверка ожидаемого состояния `GameState`;
  - проверка ожидаемых событий.

Это особенно важно для сохранения детерминированности симуляции при развитии проекта.
