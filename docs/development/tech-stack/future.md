# Планируемые технологии (Post-MVP)

Эти технологии рассматриваются как задел под мультиплеер и крупные карты, но не реализуются в первом MVP:

## Серверная часть

- **Node.js + Socket.io** — сервер реального времени:
  - управление подключениями игроков;
  - рассылка изменений игрового мира;
  - базовая синхронизация состояний.
- **FastAPI (Python)** — сервер игровой логики (расширенный вариант):
  - сложные расчёты (экономика, аналитика, сценарии);
  - REST/GraphQL API для внешних инструментов.

## Базы данных

- **PostgreSQL** — основная БД для:
  - долгосрочного хранения миров;
  - сохранений городов и пользователей.
- **Redis** — кэш и хранение актуального `GameState`/чанков на сервере.

## Инфраструктура разработки

- **Docker / Docker Compose**:
  - локальная среда разработки (клиент + сервер + БД + Redis);
  - воспроизводимость окружения.
