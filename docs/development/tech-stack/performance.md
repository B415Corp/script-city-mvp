# Производительность

Основные подходы к производительности:

## Чанкинг карты

- карта делится на чанки (например, 64×64 или 128×128 тайлов);
- в памяти и в рендере находятся только видимые и соседние чанки;
- сохранение/загрузка производится на уровне чанков.

## Viewport-based rendering (culling)

- PixiJS-рендерер получает только те спрайты, которые попадают в текущий viewport камеры;
- объекты вне экрана не создаются или деактивируются.

## Фиксированный шаг симуляции

- отдельная частота тиков (например, 10–20 тиков/сек);
- FPS рендера может быть выше и не обязан совпадать с частотой тиков;
- при просадках возможен прогон нескольких тиков подряд без промежуточного рендера.

## LOD (Level of Detail)

- для отдалённых участков используются более простые модели и агрегации;
- детальные расчёты включаются только для области вокруг камеры.

## Spatial indexing

- использование пространственных структур (сетки, деревья) для быстрого поиска объектов на карте;
- критично для транспорта, инфраструктуры и событий.
