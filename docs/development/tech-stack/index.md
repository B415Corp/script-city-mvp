# Технический стек

Последнее обновление: 2025-11-23

Документ описывает целевой технический стек для SimCity-подобной игры Script City. Акцент сделан на:

- большом мире (большая тайловая карта, чанки),
- глубокую симуляцию (экономика, транспорт, население),
- возможность эволюции к мультиплееру в следующих версиях.

## Навигация по документации

- [Клиентская часть (игровой движок)](./client.md) — TypeScript, PixiJS, ECS, UI-слой
- [Инфраструктура и инструменты](./tools.md) — Vite, ESLint, тестирование
- [Производительность](./performance.md) — оптимизации, чанкинг, LOD
- [Планируемые технологии (Post-MVP)](./future.md) — сервер, БД, мультиплеер

---

Документ является рабочей основой и может дополняться по мере уточнения архитектуры и появления новых требований к производительности и мультиплееру.
