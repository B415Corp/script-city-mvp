# Этап 1: Базовая карта и редактор

**Теги**: `stage:mvp-1`, `map:isometric`, `map:chunks`, `gameplay:editor`, `gameplay:construction`, `status:mvp`

**Цель**: Создать игровую карту и базовый редактор для размещения дорог и зон.

---

## Компоненты

### 1.1. Карта и чанки

**Теги**: `map:isometric`, `map:chunks`, `arch:infrastructure`

- Тайловое поле (изометрическая проекция)
- Система чанков (100×100 клеток на чанк, подготовка)
- Загрузка/выгрузка чанков по viewport (заглушка для MVP)
- Рендеринг видимой области

📖 **Документация**: 
- [Взаимодействие с картой](../../simulation/map-interaction.md)

### 1.2. Модуль "Городская карта"

**Теги**: `arch:module`, `arch:ecs`, `map:isometric`

- Компоненты: `PositionComponent`, `TileComponent`
- Система управления тайлами
- Базовые типы тайлов (земля, вода)

📖 **Документация**: 
- [Модули симуляции](../../architecture/modules.md)
- [Минимальное ядро MVP](../../architecture/mvp.md)

### 1.3. Редактор дорог

**Теги**: `gameplay:construction`, `transport:road-network`, `gameplay:editor`

- Инструмент размещения дорог (1-3 клетки ширины)
- Автоматическое соединение дорог
- Визуализация сетки
- Снос дорог

📖 **Документация**: 
- [Транспортная система](../../../ideas/game-concepts/transport.md) (модель дорог)

### 1.4. Редактор зон

**Теги**: `gameplay:zoning`, `building:zoning`, `building:residential`, `building:commercial`, `building:industrial`

- Инструмент зонирования (жилые, коммерческие, промышленные)
- Размещение зон на карте
- Визуализация зон (цветовая индикация)
- Удаление зон

📖 **Документация**: 
- [Типы зданий](../../../ideas/game-concepts/buildings.md) (зональная застройка)

---

## Критерии готовности

- ✅ Карта отображается в изометрии
- ✅ Можно размещать/удалять дороги
- ✅ Можно размещать/удалять зоны
- ✅ Камера двигается и зумится
