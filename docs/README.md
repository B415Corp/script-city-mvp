# Документация Script City

## Для разработчиков и агентов

- [AGENTS.md](../AGENTS.md) — контракт проекта с ИИ-агентами: стек, команды, инварианты,
  запреты, Definition of Done, известные проблемы.
- [development/code-style.md](development/code-style.md) — правила написания кода:
  именование, типы, импорты, логирование, ECS, модули, тесты.
- [development/workflow.md](development/workflow.md) — процесс разработки: ветки, коммиты,
  PR, версии, релиз, работа с агентами.
- [ecs-workflow.md](ecs-workflow.md) — как писать компоненты, системы, кластеры и фабрики.
- [../CHANGELOG.md](../CHANGELOG.md) — история изменений.

## Дизайн и продукт

- [../design.md](../design.md) — ТЗ для дизайнера: изометрия, тайлы, здания, транспорт,
  освещение и время суток, эффекты, UI, ассеты.
- `../README.md` — легаси-описание проекта: концепция, стек, ориентиры по городам
  (SimCity, Cities: Skylines, Tropico), роадмап MVP и post-MVP.
  **Внимание:** документ местами устарел и ссылается на несуществующие файлы в
  `docs/development/*`; требуется постепенная актуализация.
