## 📋 Ключевые особенности проекта

- ✅ **Модульная архитектура** — Feature-Sliced Design (FSD)
- ✅ **Расширяемость** — Plugin-based подход, API для модов
- ✅ **Региональная система** — карта из регионов 100×100 клеток
- ✅ **Гибкая застройка** — здания и дороги переменного размера
- ✅ **Система политик** — законы, применяемые к регионам
- ✅ **Реалистичная экономика** — социальные группы, спрос и предложение
- ✅ **Сложная транспортная система** — ПДД, аварии, любой вид транспорта
- ✅ **Мультиплеер (задел)** — регионы за разными игроками

## 🛠 Технологии

- **Frontend**: React, TypeScript, Redux Toolkit
- **Build**: Vite
- **Styling**: Tailwind CSS
- **Testing**: Vitest
- **Architecture**: Feature-Sliced Design (FSD)
