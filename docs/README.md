## 📋 Ключевые особенности проекта

- ✅ **Модульная архитектура** — Ядро + независимые модули симуляции (ECS)
- ✅ **Расширяемость** — Plugin-based подход, событийная шина, API для модов
- ✅ **Тиковая симуляция** — фиксированный шаг, независимый от FPS
- ✅ **Большие карты** — чанкинг, viewport culling, LOD
- ✅ **Региональная система** — карта из регионов 100×100 клеток
- ✅ **Гибкая застройка** — здания и дороги переменного размера
- ✅ **Система политик** — законы, применяемые к регионам
- ✅ **Реалистичная экономика** — социальные группы, спрос и предложение
- ✅ **Сложная транспортная система** — ПДД, аварии, любой вид транспорта
- ✅ **Мультиплеер (задел)** — архитектура готова к серверной симуляции

## 🛠 Технологии

- **Клиент**: TypeScript, Phaser (2D/изометрия), ECS-архитектура
- **Build**: Vite
- **Testing**: Vitest / Jest
- **Architecture**: Модульная архитектура (Ядро + Модули симуляции)
- **Post-MVP**: Node.js + Socket.io, FastAPI, PostgreSQL, Redis
